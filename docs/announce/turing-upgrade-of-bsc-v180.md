# Turing Upgrade of BSC (v1.8.0)

**Client:** BSC · **Version:** v1.8.0 · **Type:** Hardfork · **Mandatory upgrade**

- Mainnet activation: **2026-12-10 02:30 UTC** (<span data-si-countdown="2026-12-10T02:30:00+00:00"></span>)
- Testnet activation: **2026-11-20 02:30 UTC** (<span data-si-countdown="2026-11-20T02:30:00+00:00"></span>)
- [Release notes](https://github.com/bnb-chain/bsc/releases/tag/v1.8.0)

BSC v1.8.0 is now ready for upgrade. It enables the **Turing hardfork**.

### Activation Schedule
- **Mainnet activation:** 2026-12-10 02:30:00 UTC
- **Chapel testnet activation:** 2026-11-20 02:30:00 UTC

This upgrade is **mandatory** for all validators and full nodes. Nodes that do not upgrade before activation will fork off the network.

### What's New
- **BEP-990:** faster finality vote aggregation
- **BEP-991:** lower base fee floor for system transactions
- **Fix:** snapshot sync stalls after a long reorg
